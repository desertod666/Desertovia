# Дезертовия 0.7.17 — подготовка выпуска

Источник: работа Вадима [PR76](https://github.com/desertod666/Desertovia/pull/76),
точный b617f8d9f38fcc700400dbf2e7239f931d8d2127. Выпуск отдельно от1.0,
поверх принятой0.7.16 и документации main b9b4b32. Разрешение владельца21.10
на коммит и живую установку подтверждено отдельно после обновления цели.

Четыре уровня топоров и кирок: дерево5 применений/×1, камень8/×1.25,
железо12/×1.5, сталь20/×1.75. Бонус относится к выходу за цикл, время работы
не сокращается. Выбирается лучший уровень, при равенстве самый изношенный.
Рецепты/открытия и прежняя графика автора сохранены. Износ виден в руках,
на общем складе и в сообщении о поломке. Личный экономический инвентарь
по-прежнему хранит количество; это отдельный путь от рабочих инструментов.

Обзор выявил выдачу бонусного золота после списания базовой добычи из жилы.
Исправление: сначала весь выход с бонусом, затем ограничение/списание остатка.
Два регрессионных случая проверяют полную жилу и последнюю единицу.
API migration regression проверяет JSON0.7.16 без Durability, незавершённую
работу, оружие с заточкой, перезагрузку и два разных износа одного инструмента.

Готовность: точный финальный CI (Domain/API, обе browser-части, unit/lint/build/
Docker), свежая live-проверка, резервная копия PG с проверкой восстановления,
проверка профилей/привязок/навыков/характеристик/номеров зданий, установка только
точного образа, отдельная независимая проверка SHA/0.7.17/входа/миграций.
При активном данже ждать естественного завершения. Бот/его настройки и прочие
службы не обновлять. Сырые профили/ключи/БД не публиковать. Автооткат старого
JSON writer после миграции запрещён; копии и данные сохранять для разбора.

Статус: PREPARED, не установлена. Локально548Domain PASS. Финальная квитанция
и ограничения будут добавлены после проверок и фактической установки.
