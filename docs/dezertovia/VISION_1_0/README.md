## Как продолжить

Это план всей игры, а не только фермы. Сверить свежие AGENTS.md, исходники,
ветки и изменения коллег. Пакет изучал game4bb125f и bot8dbbc3a;
свежая проверка перед реализацией обязательна. Переиспользовать существующие
системы, не переписывать их ради документа. Отделять PLAN, implemented,
verified и released. Открытые решения блокируют только зависимое поведение.

Дополнение фермы — предложение к общему контракту, пока без новых карточек
в основном DAG. Перед её реализацией связать с T021/T022/T026 и обновить
соответствующие проверки. Нынешние47заданий и40сценариев не объявляются
полной готовой спецификацией уже изменённого фермерства.

Эта публикация разрешена поручением владельца помочь другому ИИ найти файлы.
Она касается только документации. Ни публикация, ни старые разрешения на
конкретные патчи не запускают разработку всей1.0 или установку на сервер.
Приватные исходники батюшки по-прежнему требуют отдельного доступа;
секретов, данных игроков и настоящих БД в пакете нет.

PACKAGE_MANIFEST.json описывает оригинальный ZIP и вложенные документы.
Этот README и скачиваемая копия ZIP — обёртка публикации вне его списка файлов.
