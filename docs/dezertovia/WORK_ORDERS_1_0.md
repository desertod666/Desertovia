# Явная собственность и фонд производственных госзаказов

Срез PKG-T021/T022 поверх себестоимости T020. Это часть M2; строительство,
исследования и общий урожай расширяют договор отдельно. Они не объявлены готовыми.

Работа сохраняет CycleOwnership, CyclePaymentMode и ссылку на принятое
обязательство. PrivateExtraction/PrivateCraft используют только личные материалы
и результат; крафт требует своей мастерской. PublicContract использует общественные
материалы и даёт общине весь результат. Публичная ноша не становится личным товаром.
Выбор места больше не единственный способ определить эти условия. Старые клиенты
сохраняют прежний выбор места; новая явная личная работа доступна из окна экономики.

Для каждого мира владелец может явно включить оплату новых общественных работ
только по заказам. Переход не переписывает уже принятые циклы: их режим оплаты
сохранён. В новых мирах и при миграции переход автоматически не включается.
Без заказа новая общественная работа после перехода добровольная и без зарплаты;
интерфейс показывает это и направляет к заказам. Налог и курс валют этим не меняются.

WorkOrder — версия1, одна конкретная производственная задача Resources,
1–1000 полезных циклов,1–1000 хозяйственных монет за цикл, срок приёма до30 дней.
Единица количества — законченный полезный цикл, не обещание фиксированного выхода:
выход сохраняет действующие навыки/погоду/инструменты. Начисление не идёт за клики.
Публикация целиком переносит бюджет из свободной казны в отдельный резерв.
Казну можно пополнить передачей из собственного кошелька; скрытой эмиссии нет.
Изменения — в существующем WithVillageAsync с PG advisory transaction lock.

При старте сохраняются работник, начало цикла, обещанная сумма и конкретный заказ.
Последнее место нельзя занять дважды. У команды есть RequestId/fingerprint:
потерянный ответ и поздний повтор не начинают следующий цикл и не меняют условия.
Публикация, закрытие и пополнение используют существующие EconomyReceipt.
Губернатор/житель не получает прав владельца на фонд; чужой мир не может принять заказ.

Отмена/истечение возвращает только резерв непринятых циклов. Уже принятая работа
может закончиться после закрытия, отключения или запроса отдыха и получить оплату
ровно один раз. Неудавшийся/отменённый самим работником цикл не оплачивается:
его место открывается снова, либо деньги возвращаются казне после закрытия.
При полном кошельке результат работы остаётся завершённым, заработанное — Payable
в физическом денежном резерве; получение позже переносит его в кошелёк один раз.
Резерв + свободная казна + кошельки сохраняют сумму; журнал содержит обе стороны.

Миграция FundedWorkOrders добавляет поля и две таблицы. Старые предметы,
стоимость, профили и деньги не преобразуются. Перед локальной миграцией42 сохранён
отдельный pg_dump; публичная игра и бот не обновлялись. Откат требует штатного
backup/restore: удалять принятые обязательства старой версией кода нельзя.

Интерфейс: сворачиваемые госзаказы, форма владельца, выбор личной работы,
короткие условия в44px подсказках. Повторить законченный договор означает выбрать
следующий оплаченный цикл; кнопка повтора не начинает молча неоплаченный цикл.
Личная работа при повторе сохраняет собственность результата.

Проверено564 Domain,4 первоначальных API на PostgreSQL и8 финальных browser RU/EN desktop/phone.
Расширенный API-набор добавляет выход из мира, полный кошелёк и старые receipts;
его свежий прогон и полный CI проверяются отдельно.
Сборка/lint проходят после финальных правок формы; полный CI нового дерева
запускается отдельно. ECONOMY_COST_VERIFICATION_1_0.json относится к предыдущему
точному SHA28dc1a6 и не выдаётся за проверку госзаказов.

Далее: общий фонд урожая F004 с сохранёнными вкладами, staged construction pay,
рынок поставок T023, налог/оборот T024/T025 и экономика5/10/20 игроков F006/T026.
Конкретные ставки/эмиссия из OPEN D109 не активированы этим срезом.
