# Округа и маршруты1.0

T033, первый срез. Основа пакета — VISION§10 и ROADMAP M3: разнообразие мест
и связей вместо пустых клеток. Старый WorldMap.Land120×90 и1350 байт explored
сохраняются. Увеличение площади и удалённые регионы ещё не реализованы.

WorldRoutes.Discover строит проекцию пяти существующих мест: поселение,
оленьи леса, горная пещера, дозорная вершина и золотая жила. Устойчивые route ID
и district ID предназначены также для будущего контракта похода. Пещера и
вершина берутся из сохранённого Wilderness, не генерируются заново. Ресурсы
описывают существующие занятия, не обещают находку за переход или нажатие.

Проекция использует тот же seen bitmap, что отправляется клиенту: учитываются
уже пройденные части Trip. В route DTO координаты ещё не разведанной цели
отсутствуют. Известная цель за разрушенным/непостроенным мостом остаётся известной,
но содержит bridge reason; правила BankAccess продолжают запрещать переход.
Эта проекция не изменяет действующий формат остальных Wilderness DTO.

WorldAtlas показывает компактный выбор мест и детали выбранного. «Показать
на карте» меняет только камеру существующего Pixi renderer: не движение героя,
не туман, не вход в бой, не ресурсы. Просмотр доступен без нового рабочего цикла.
Никакого фонового расчёта всех клеток и новой БД на этот обзор не добавляется:
пять записей вычисляются при существующем полном snapshot. Старый клиент/сервер
без worldRoutes сохраняет прежний экран.

Следующие интеграции:

- T033: дополнительные маршруты и реальные ограничения пути/события, отдельные
  устойчивые данные удалённого региона при расширении мира; миграция fog без
  переиндексации старого города; ограниченная загрузка и профиль T004.
- T030/T034: соглашение группы и снабжение, server-side lifecycle дороги и
  возвращения, один результат без teleport товаров. Обзор мест этого не заменяет.
- T031/T032/T035: боевой участок маршрута и проверка reconnect/препятствий;
  старый одиночный loot-roll не становится автоматически групповым приключением.

Приёмка T033 в целом остаётся открытой. Текущие проверки покрывают проекцию,
сохранность данных и поведение обзора; они не доказывают увеличение территории,
полный поиск пути или готовность походов.
