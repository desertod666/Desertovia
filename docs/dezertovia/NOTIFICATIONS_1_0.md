# Уведомления и настройки аккаунта

21.10.2026 Europe/Oslo. T064, браузерный канал при открытой игре.
Это часть общей1.0; доставка при закрытой игре и правила доступа по группе
ещё требуют отдельных интеграций. Существующие civic/daily digest сохранены.

## Поведение для игрока

В настройках находится короткая карточка, дополнительные поля свёрнуты.
Разрешение спрашивается только по нажатию игрока. По умолчанию уведомления
выключены. Старое не привязанное к аккаунту браузерное разрешение не включает
их для другого человека на том же устройстве.

Аккаунт хранит категории: работа, стройка, урожай, приключения, опасность,
голосования. Тихие часы используют часовой пояс IANA, например Europe/Oslo,
включая переходы на летнее/зимнее время. Разрешение конкретного браузера
остаётся отдельным: вход на втором устройстве не выдаёт его автоматически.
«Отключить для аккаунта» выключает общий браузерный канал; перед отправкой
очередной партии клиент перечитывает настройки с сервера.

События объединяются по царству и категории в течение3 секунд. Опасность
может отправляться без этого ожидания. Событие в открытой активной игре
считается прочитанным. Повтор того же события, восстановление связи или
параллельная вкладка не должны давать повторное сообщение. Хранятся только
ограниченные ID и сроки, без текста сообщений и игрового состояния.

Каждое событие имеет время возникновения и срок актуальности. Старый набег
не напоминает о себе после тихих часов; закончившийся сбор в данж и уже
собранная грядка удаляются из очереди. Для урожая отслеживается переход
наблюдаемого посева к зрелости; первый снимок давно выросших грядок не
порождает серию сообщений. На полив отдельные оповещения не отправляются.

## Интеграция и гарантии

- `NotificationPreferenceService`: GET/PUT `/api/me/notification-preferences`,
  только текущий авторизованный аккаунт. Revision предотвращает незаметное
  затирание другой вкладкой/устройством. Request ID и fingerprint позволяют
  повторить запрос после утраты ответа. Повтор старого разрешения после
  последующего отключения возвращает текущие настройки и не включает их снова.
- PostgreSQL transaction/account advisory lock: настройки и квитанция
  фиксируются вместе. Ошибка на последнем commit откатывает оба изменения.
  Обновления не меняют деньги, работу, персонажей и отчёты.
- Миграция48 `AccountNotificationPreferences`: две таблицы с FK на Accounts,
  без массового переноса старого локального opt-in. GET отсутствующей настройки
  возвращает выключенный канал и не создаёт запись.
- `NotificationDelivery`/`NotificationProvider`: ограниченная очередь100 событий,
  журнал до500 ID, срок хранения до7 дней. Нет сети для проверки согласия —
  нет отправки; число попыток ограничено. Смена аккаунта отменяет его очередь.
- Web Locks сериализуют заявки вкладок на одном origin, localStorage хранит
  общие ID. Без Web Locks межвкладочная защита имеет best-effort гарантию;
  строгая доставка на все физические устройства не заявлена.
- Отметка попытки сохраняется перед вызовом браузера. Это защита от повторного
  вызова после падения, не гарантия показа ОС: при падении между отметкой и
  показом уведомление может быть потеряно. Игровой результат остаётся в игре.
- `CycleReport` передаёт начало/окончание работы и время расчёта;
  `VillageEventsDto.At` даёт серверное время партий. Их потребитель никогда
  не начинает повторно работу или расчёт награды ради доставки уведомления.

## Проверки и незавершённый объём

Domain: defaults/validation, тихие часы/DST, сохранение идентичности завершённой
работы при безопасном отдыхе. API: права, два устройства, конкурентные ревизии,
невалидные настройки, повтор после утраты ответа и настоящая ошибка финального
PostgreSQL commit. Клиент: агрегация, сроки, отзыв согласия, offline, account
switch, ограниченные очереди и межвкладочные ID. Браузер: RU/EN,320/1280px,
темы, сохранение черновика/request ID, две вкладки и явный отказ разрешения.
Тестовые Notification заменены заглушкой; реальные сообщения людям не отправляются.

Точные результаты и проверка миграции/перезапуска —
`IMPLEMENTATION_PROGRESS_1_0.json`. T064 в целом остаётся открытой: Web Push
при закрытом приложении, мобильные ограничения ОС, Telegram-канал по отдельному
согласию и согласованная политика группы PKG-D113 ещё не подтверждены. Доступ
к игре не перекрывается неподтверждённой проверкой членства.

Следующий независимый этап общего DAG — T033: реальное расширение округи,
сохранность тумана, проходимость и путь туда/обратно. Новая карта должна работать
с T030–034, а не оставаться только списком мест в атласе. Договор группы и
трофеи ожидают уже заданных вопросов; независимые этапы продолжаются.
